# Plan: Eunomia Logo

## Task
Design and create a simple, clean, aesthetic logo for the website **Eunomia (`eunom.ia`)**.

## Visual Style
- **Colors**: Dark Ink (`#171A1F`), Burnished Bronze (`#82510E`), Off-White Canvas (`#F7F5F0`).
- **Concept**: Minimalist geometric mark combining an archival block node with an "E" monogram, plus "eunom.ia" text using Playfair Display serif.
- **Rules**: Keep it simple, sharp, clean, and modern. No generic AI glowing effects or complicated 3D shapes.

## Files to Create
1. `public/favicon.svg` (Clean 32x32 icon)
2. `public/logo.svg` (Full logo with mark + text)
3. `src/components/Shell/Logo.tsx` (React component displaying the logo)
